# 審問の時間です。

制作：高無メイ

## 起動

配布ZIPをすべて展開し、index.htmlを開いてください。外部ライブラリーや通信なしで遊べます。Web公開する場合は、index.htmlと同じ階層にapp.js、data.js、style.css、audio-manifest.js、assetsを配置します。GitHub Pages / Cloudflare Pagesでも静的配信できます。

7人・28Phase・全5エンド。全分岐597セリフ。BGM007/008と無音。SEは入退室時の扉音（se-014）のみ。

## 音声の登録

ボイス未収録の確認版です。自動読み上げは使用しません。

1. 台詞IDと同じ名前で、収録音声をvoices/人物コード/に配置。
2. audio-manifest.jsにIDと相対パスを登録。

```js
window.VOICE_MANIFEST = {
  'KAYO-IN-01': 'voices/KAYO/KAYO-IN-01.wav',
  'YUTO-IN-01': 'voices/YUTO/YUTO-IN-01.mp3'
};
```

WAV・MP3の両方に対応。voice-manifest-template.jsonは全IDの登録例です。ファイルを配置した後、内容をwindow.VOICE_MANIFESTに設定してください。未登録IDは無音で進みます。音声が長くても「次へ」で読み進められ、前の音声は停止します。

キャラ別音量には全体音量とボイス全体を掛けます。BGMには全体音量とBGM音量を掛けます。各0～100%、設定を自動保存。

## 操作

会話の「次へ」で進み、各Phaseの供述を最後まで聞いたあと、左右で読み返し。「詳しく聞く」と「嘘を指摘する」で確認します。詳しく聞くで変更される指定箇所だけ供述を更新し、通知と発光を表示。更新済みの供述は再質問不可。変更されない返答は聞き直せます。

会話終了は確認後にそのPhaseを未発見のまま終了。資料は各Phase開始時に追加され、過去の成否に依存しません。ファイル内で人物情報・事件資料・暴いた嘘を確認。

メニューからオプション・セーブ3スロット・ロード・音声再生・タイトルへ。オートセーブあり。保存先はブラウザーのlocalStorageです。別端末・別ブラウザー・公開URLとローカル版で共有されません。ブラウザーのデータ削除で消去されます。

## 評価

各人物PERFECT=2、GOOD=1、BAD=0。最初の6人で4点以下END1、5～7点END2、8点以上で7人目解放。7人目BAD=END3、GOOD=END4、PERFECT=END5。

## 収録台本

役者別8ファイル、台詞ID・表情・本文。BGM指定なし。全分岐を収録する前提の数です。
集計は本文のみ、句読点（。等）・記号（…等）・本文中の空白も含みます。ID・表情・見出し・ファイルの改行を除外。異なるIDに同じ本文がある場合もそれぞれ数えます。

## 確認項目

千尋の非正解箇所28件は正本に「補完案（不正解用）」とある選択肢を実装しています。文面の最終確認対象です。
ボイスは音声データ登録後に実音で音量・音切れ・収録漏れを確認してください。
キャスト名・BGM提供者等の正式クレジットは確定情報を反映してください。
